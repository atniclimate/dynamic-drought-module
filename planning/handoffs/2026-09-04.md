## What the project is

The Dynamic Drought Module (DDM) is an embeddable, serverless TypeScript and MapLibre web
map of drought, wildfire, heat, water, and ENSO conditions built by ATNI Climate for Tribal
Nations, agencies, and researchers: a static Vite build on GitHub Pages plus an optional
Cloudflare Worker that is only an allowlisted, body-transparent CORS shim. Truthfulness is
interface design: six honest layer states, visible sources and qualifications, no invented
severity score. The eventual host is a local full-service server with pre-processing;
GitHub Pages stays the fast static host until then. The Convention framing, from the ATNI
Board President's remark: Tribal sovereign capacity in action, not a technology demo.

## Session gotchas worth keeping

- **A lane agent cannot invoke another agent.** It has no Task tool. A charter that says
  "use the `ddm-science-verifier` agent" asks for something structurally impossible. Either
  the orchestrator runs it and hands over the verdicts, or the charter tells the lane to run
  the agent's PROCEDURE in-lane and say that it did. One lane hit this and handled it
  correctly.
- **`npm run verify:smoke` cannot be launched in the same Bash call that waits for the port
  lock.** `.claude/hooks/ddm-guard-bash.py` inspects the command at launch and checks port
  4173 at that instant, so it blocks while another lane still holds it. Use three calls:
  wait for the lock and the port in a backgrounded call, run the suite in a second, release
  in the third.
- After a Playwright run ends, `netstat` shows a hundred-plus sockets on 4173 in `TIME_WAIT`
  and no `LISTENING` socket. That is spent residue, not a held port. Do not kill anything on
  the strength of a `TIME_WAIT` list.
- **Editor diagnostics from a worktree lie during a lane's run**, especially while a lane is
  stashing to prove a baseline. Three times this run, diagnostics contradicted a lane's
  "typecheck green" claim; all three pushed commits typechecked clean. Verify the COMMIT,
  not the editor.
- **Prove a new assertion red before making it green.** Three lanes did this today, two
  unprompted, and it is the difference between a test that catches the defect and one that
  passes vacuously.
- Heredocs containing backslashes are blocked by a hook: write the script or message to the
