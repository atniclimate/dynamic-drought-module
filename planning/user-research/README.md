# User research intake

Ignored planning directory. One file per observation session, named
`YYYY-MM-DD-<who-by-role>.md`, written from `TEMPLATE.md`. The owner writes the
prose; an agent later files each observation against the decision register
(`Source: User research`) so that user evidence, not audit findings, reorders
the plan.

Rules

- People appear by role and organization type, never by name, unless they have
  asked to be named. Tribal Nations appear by full formal name only when the
  Nation has agreed to be identified; otherwise "a Tribal natural-resources
  program in the Northwest".
- Record what the person did and said, then separately what we infer. Do not
  merge the two.
- Nothing here is a commitment. A decision changes only when the register
  records it.
- No em dashes (U+2014). Capitalize Tribe, Tribal, Treaty.

Filing: after the owner writes an entry, run the triage described in
`planning/decisions/2026-09-03-decision-packet.md` Part 0, which lists the open
decisions most likely to move on user evidence.
